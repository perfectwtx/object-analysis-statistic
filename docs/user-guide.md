# 前端使用指南

更新：2026-10-21。安装与环境配置见 [README](../README.md)，生产托管见 [部署说明](deployment.md)。

## 开始分析

1. 在“分析”页面上传文件、粘贴文本，或加载内置样例。样例同样提交到后端分析。
2. 打开“配置”，选择 Runtime、规则或 Features。规则支持可视化编辑与 JSONC；草稿修改后需点击“应用规则”才会用于下一次分析。
3. runtime 可配置嵌套展开、CSV 数字推断、过滤、路径、采样和并行度。规则字段选择和过滤优先于运行参数中的同名设置。
4. 应用规则后，预检可能提示字段不匹配。可根据样本字段调整规则，也可明确继续。
5. 在字段明细、深度分析、取值分布和质量报告之间切换。未开启的特征与无数据状态会分别提示。

文件达到 2 MiB 时默认异步，也可以强制后台分析。进度连接失败时会转为轮询。取消操作会提示是否已经请求取消；后端取消失败时不能假定任务已停止。离开页面仅停止本地进度跟踪，后台任务仍可继续。

## 平台页面

- 总览与质量页展示真实作业、指标和问题；缺失分数显示“暂无数据”，真实空库不会自动出现样例。
- 后端关闭或未实现的模块显示不可用状态，失败模块可以单独重试；一般页面切换会复用 30 秒内的总览数据，刷新按钮会重新加载。
- 字段、关系、血缘和影响页需要作业 ID。切换作业会取消旧请求，旧响应不能覆盖新选择；血缘等页也可手动输入 ID。
- 告警开关保存到后端后才更新本地状态，失败时保留原值。保存期间不能重复提交。
- 基线、建议、回归等内容依赖部署的 API；页面入口不表示后端已实现对应能力。

部署显式配置 `VITE_DEMO_MODE=true` 时，总览、趋势、字段、问题、基线与告警可展示演示样例，并有页面提示。演示告警切换仅本地生效。分析和其他洞察依然需要后端。

## 导出

工作台支持 JSON、CSV、Markdown、HTML、JSON Schema、Excel；当前没有 PDF 按钮。导出会显示进行中和失败反馈。

CSV 会保护公式前缀并正确处理逗号、引号及换行，可能在文本前增加单引号。若需要保持原始文本用于程序处理，选择 JSON。Schema 是根据字段统计推断的结构，不能替代完整业务契约。

## 语言、主题与键盘

右上角可切换中文／English，以及系统、浅色、深色、护眼主题。部分由服务器返回的错误、样例规则注释、文件内容和导出列名保留原文。

弹窗会将 Tab 焦点留在内部，Shift+Tab 反向移动，Escape 关闭最上层可关闭弹窗，关闭后恢复触发按钮焦点。后台提交或确认处理中可能禁用关闭，避免操作中断。

桌面侧栏分隔条可通过鼠标拖动；聚焦分隔条后，左右方向键每次调整 16px，Home／End 分别到达最小／最大宽度。窄屏改为上下布局，不显示拖拽分隔条。

## 常见问题

- **显示后端离线**：确认 .NET 服务已启动，API 前缀与代理正确；开发代理默认指向 localhost:5200。
- **列表为空**：可能是首次使用或当前作业没有结果，不等于接口故障。
- **部分功能不显示**：检查后端 capabilities 声明；未知能力保留兼容，明确 false 才禁用。
- **分析页刷新 404**：生产站点需要 BrowserRouter 的 index.html 回退，API 与资源路径不能回退为首页。
- **规则清空后**：字段规则、解析器和数据集期望被清空，运行时 flatten 设置保留；重新运行不会携带旧字段规则。
- **上传后进度长时间不变**：检查网络、SSE 代理缓冲、后端状态与任务是否过期。不要将本地停止跟踪等同于服务端取消。
